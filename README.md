# .github

Repositorio de configuración de la organización **NobodyWorks**.

No contiene código de ningún proyecto. GitHub lee de aquí los archivos que se aplican
a toda la organización.

| Ruta | Para qué sirve |
|---|---|
| `profile/README.md` | Contenido que se muestra en la portada pública de la organización: `github.com/NobodyWorks` |

Si más adelante quieres plantillas de issues, de pull request, un `CONTRIBUTING.md`
o un `SECURITY.md` comunes a todos los repos, van también en este repositorio y
GitHub los usa por defecto en cualquier repo que no tenga los suyos propios.

Este repositorio debe ser **público** para que la portada se muestre.
